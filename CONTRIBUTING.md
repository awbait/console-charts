# Правила контрибуции

## Перед началом работы

- Создайте ветку `feature/`, `fix/`, `chore/`, `refactor/`, `style/`, `docs/` или `test/`.
- Не коммитьте и не пушьте напрямую в `main`.
- Перед изменением чарта прочитайте `CONVENTIONS.md` и документацию этого чарта.
- Не добавляйте в Git архивы чартов, вендорные зависимости и `Chart.lock`.

## Коммиты

- Пишите сообщения коммитов на английском в формате Conventional Commits.
- Для изменений конкретного чарта scope обязателен и равен имени чарта:
  `feat(project): ...`, `fix(ingress-gateway): ...`, `chore(namespace): ...`.
- Для общерепозиторных документации, шаблонов и настроек scope можно не указывать:
  `docs: add contribution guidelines`, `chore: ignore local workspace files`.
- Не добавляйте `Co-Authored-By`, атрибуцию ИИ и другие служебные подписи.
- Перед коммитом выполните проверки, применимые к изменению. Для чартов это Helm
  lint, Helm template и проверка значений согласно `CONVENTIONS.md`.

## Изменения чартов

Для изменений поведения чарта или его значений:

- Поддерживайте согласованность шаблонов, `values*.yaml`, `values.schema.json`, README и CHANGELOG.
- Повышайте версию по SemVer.
- Обновляйте версии зависимых чартов, если это необходимо.
- Перед PR выполните требуемые Helm-проверки.

## Язык

- Описания pull request, ответы в review, комментарии к issue и обсуждения ведите на русском.
- Документацию (`README.md`, `CHANGELOG.md`) и комментарии в `values*.yaml` пишите на русском.
- Комментарии в Helm-шаблонах `templates/` пишите только на английском.

## Pull request

Используйте шаблон PR. В описании обязательно укажите:

- что было не так и почему;
- что именно изменено;
- затронутые версии чартов и зависимости;
- выполненные проверки и их результаты;
- непроведённые проверки и причину;
- влияние на совместимость.

Не удаляйте заголовки из шаблона PR. Если раздел неприменим, напишите под ним
«Не применимо» и укажите причину. Дополнительные заголовки можно добавлять в любом
месте описания.

Один PR должен содержать одну логически связанную правку.

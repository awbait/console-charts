# Changelog

Все заметные изменения чарта `subnet`
фиксируются в этом файле.

## Правила версионирования

- **MAJOR** - несовместимые изменения, требующие правок в твоём `values.yaml`.
- **MINOR** - новые возможности без поломки существующих.
- **PATCH** - исправления и улучшения, прозрачные для пользователя.

## Категории изменений

- **Added** - что появилось нового.
- **Changed** - что изменилось в поведении.
- **Deprecated** - что будет удалено в будущем.
- **Removed** - что удалено.
- **Fixed** - что исправлено.
- **Security** - изменения, влияющие на безопасность.

---

## [1.1.0] - 2026-10-13

### Added

- Опциональная автоматическая привязка к namespace через namespaceBinding и общие значения Helm.
- Наследование назначения подсети из назначения namespace при пустом subnet.name.

## [1.0.2] - 2026-10-13

### Changed

- Оформление трёх файлов values приведено к образцу других чартов: шапки, секции и русские комментарии с описанием параметров.
- README приведён к конвенциям репозитория: удалены команды установки и проверки.

## [1.0.1] - 2026-10-13

### Added

- SVG-иконка подсети в стиле других чартов, встроенная в Chart.yaml.

## [1.0.0] - 2026-10-13

### Added

- Независимое управление Subnet kube-ovn: CIDR, NAT, исключения IP, тип шлюза, изоляция, разрешённые подсети и namespace.
- Схемы значений и представлений Console, примеры и документация.
- Обязательный диапазон 172.30.0.0/15 в allowSubnets.

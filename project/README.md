# project

Чарт создаёт проект платформы Alauda (`Project`) и раздаёт ему квоты ресурсов по
кластерам. Проект - верхнеуровневая единица: внутри него потом создаются
namespace'ы и распределяются ресурсы.

## Что создаёт чарт

| Что создаётся | Когда                                                                       |
|---------------|-----------------------------------------------------------------------------|
| `Project`     | Всегда, когда чарт включён: имя, отображаемое имя, описание и кластеры с квотами |

Ресурс создаётся, только когда чарт включён. Это служебный флаг, его проставляет
консоль при заказе.

## Теги окружения и проекта

Секция `identity` задаётся один раз на релиз. В имя `Project` эти теги не
входят - оно берётся из `project.name`, - но проставляются на все ресурсы чарта
как labels, по которым ресурсы находятся в кластере.

| Поле                | Что это                                                                       |
|---------------------|--------------------------------------------------------------------------------|
| `identity.instance` | Тег инстанса окружения. Обязателен, значение из таблицы ниже                    |
| `identity.cluster`  | Тег кластера окружения. Обязателен, значение из таблицы ниже                    |
| `identity.project`  | Тег проекта. Обязателен, до 9 символов: строчные латинские буквы, цифры и дефис |

Тег `identity.cluster` означает окружение, куда ставится релиз, и не связан со
списком кластеров проекта из секции `clusters`.

Пара тегов окружения:

| Окружение      | `identity.cluster` | `identity.instance` |
|----------------|--------------------|---------------------|
| Infra-dev-ecpk | `inf`              | `in`                |
| dev-ecpk       | `dev`              | `id`                |
| techsec-dev    | `tco`              | `ed`                |
| dev-common     | `dev`              | `ed`                |
| test-common    | `tst`              | `ed`                |
| global         | `gl`               | `pr`                |
| observability  | `obs`              | `pr`                |
| techsec        | `tcc`              | `pr`                |
| int-common     | `cmi`              | `pr`                |
| ML             | `ml`               | `pr`                |
| ext-common     | `cme`              | `pr`                |

Оба поля описаны в схеме значений перечислением, поэтому в форме портала они
выбираются из списка. Берите значения строкой таблицы: схема проверяет каждое
поле по отдельности и не поймает пару из разных окружений.

## Имя проекта

Чарт использует cpaas-нейминг, а не пятичастную схему имён остальных чартов. Имя
`Project` берётся напрямую из `project.name`, оно же проставляется в label
`cpaas.io/project`. Значение приводится к нижнему регистру и обрезается до 63
символов.

## Labels на ресурсах

| Label                          | Значение                                       |
|--------------------------------|------------------------------------------------|
| `app`                          | `project` - имя чарта, не зависит от имени релиза |
| `app.cpaas.io/name`            | Имя релиза                                     |
| `app.kubernetes.io/managed-by` | `Helm`                                         |
| `helm.sh/chart`                | Имя и версия чарта                             |
| `cpaas.io/project`             | Имя проекта из `project.name`                  |
| `ecpk/instance`                | `identity.instance`, если тег задан            |
| `ecpk/cluster`                 | `identity.cluster`, если тег задан             |
| `ecpk/project`                 | `identity.project`, если тег задан             |

Свои labels и annotations добавляются через `generic.labels` и
`generic.annotations`. Задаются только на весь релиз сразу, отдельно по ресурсам
их не задать.

## Что нужно указать

| Поле                  | Нужно указать | Что это                                                              |
|-----------------------|---------------|-----------------------------------------------------------------------|
| `project.name`        | да            | Имя проекта: строчные латинские буквы, цифры и дефис, до 63 символов   |
| `project.displayName` | нет           | Отображаемое имя проекта                                              |
| `project.description` | нет           | Описание проекта                                                      |
| `project.creator`     | нет           | Создатель проекта. При заказе из консоли подставляется автоматически   |
| `clusters`            | да            | Список кластеров с квотами, минимум один                              |
| `clusters[].name`     | да            | Имя кластера Alauda                                                   |
| `clusters[].quota`    | нет           | Квоты ресурсов кластера                                               |

## Квоты

`clusters[].quota` - это произвольный набор ключей квоты со значениями в формате
Kubernetes:

- `limits.cpu` - лимит CPU (`"1"`, `"1000m"`);
- `limits.memory` - лимит памяти (`"2Gi"`, `"2048Mi"`);
- `requests.storage` - лимит на хранилище (`"3Gi"`).

Список ключей не ограничен: можно добавить `requests.cpu`, `requests.memory` и
другие по мере необходимости.

## Когда рендер останавливается

- не задан `project.name` или в нём недопустимые символы;
- не заданы теги `identity` или их значения вне допустимых;
- список `clusters` пуст;
- у кластера в списке не задано имя.

## Файлы чарта

| Файл                  | Для чего                                                       |
|-----------------------|-----------------------------------------------------------------|
| `values.yaml`         | Значения по умолчанию: чарт выключен, ресурсы не создаются       |
| `values.minimal.yaml` | Короткий рабочий пример: один проект с квотой на одном кластере  |
| `values.full.yaml`    | Полный справочник: все параметры с пояснениями                   |
| `values.schema.json`  | Схема значений: проверка при установке и форма заказа в портале  |
